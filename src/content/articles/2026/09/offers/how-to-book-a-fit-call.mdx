Subject line that works: **FIT**

In the body, name:

1. **Licensed entity** (or clear applicant path + counsel)
2. **One workflow**
3. Whether a **decision-maker** will be in the eventual readout
4. Exam/mock date if any
5. Stack already live (custody/TR/tickets) if relevant

## We will answer

Yes (which offer) · Later (what must change) · No (not a fit)

## Please do not book if

- You want a free multi-week diagnostic
- You need us to hold keys or file a licence
- You cannot name an owner
- You want a bank modernization programme brochure
